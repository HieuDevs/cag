# Lượng từ thường dùng

Cấu trúc: số từ/这/那/哪 + lượng từ + danh từ: 一本书, 这件衣服, 哪个人. Không bỏ lượng từ: ✗ 三书 → ✓ 三本书. 个 dùng được cho nhiều danh từ nhưng dùng đúng lượng từ riêng thì tự nhiên hơn.

| Lượng từ | Dùng cho | Ví dụ |
|---|---|---|
| 个 gè | người, vật nói chung | 一个人, 一个问题, 一个苹果 |
| 位 wèi | người (kính trọng) | 一位老师, 三位客人 |
| 口 kǒu | số người trong gia đình | 我家有四口人 |
| 本 běn | sách, vở | 一本书, 两本词典 |
| 张 zhāng | vật phẳng, có mặt phẳng | 一张纸, 一张桌子, 一张床, 两张票 |
| 件 jiàn | áo, việc | 一件衣服, 一件事 |
| 条 tiáo | vật dài, mềm; quần, váy; tin tức | 一条河, 一条路, 一条鱼, 一条裤子, 一条新闻 |
| 只 zhī | con vật nhỏ; một chiếc trong cặp | 一只猫, 一只鸟, 一只手 |
| 头 tóu | gia súc lớn | 一头牛, 一头猪 |
| 匹 pǐ | ngựa | 一匹马 |
| 辆 liàng | xe | 一辆车, 一辆自行车 |
| 台 tái | máy móc | 一台电脑, 一台电视 |
| 部 bù | phim, điện thoại, tác phẩm | 一部电影, 一部手机 |
| 把 bǎ | vật có tay cầm | 一把椅子, 一把伞, 一把刀 |
| 支 zhī | vật dài, cứng, nhỏ | 一支笔 |
| 双 shuāng | đôi | 一双鞋, 一双筷子 |
| 杯 bēi / 瓶 píng / 碗 wǎn | cốc / chai / bát | 一杯茶, 一瓶水, 一碗饭 |
| 块 kuài | miếng; đồng (tiền, khẩu ngữ) | 一块蛋糕, 十块钱 |
| 家 jiā | cửa hàng, công ty | 一家商店, 一家公司 |
| 所 suǒ | trường học, bệnh viện | 一所大学 |
| 座 zuò | núi, tòa nhà, cầu, thành phố | 一座山, 一座桥 |
| 层 céng | tầng | 我住在三层 |
| 棵 kē | cây | 一棵树 |
| 朵 duǒ | hoa, mây | 一朵花 |
| 封 fēng | thư | 一封信 |
| 篇 piān | bài văn, bài báo | 一篇文章 |
| 首 shǒu | bài hát, bài thơ | 一首歌, 一首诗 |
| 节 jié | tiết học | 两节课 |
| 门 mén | môn học | 三门课 |
| 场 chǎng | trận đấu, buổi chiếu | 一场比赛, 一场电影 |
| 顿 dùn | bữa ăn; trận (mắng, đánh) | 一顿饭 |
| 份 fèn | phần, suất; tờ báo; công việc | 一份工作, 一份报纸 |
| 套 tào | bộ, căn hộ | 一套衣服, 一套房子 |
| 次 cì / 遍 biàn | lần / lượt (từ đầu tới cuối) | 去过三次, 再说一遍 |
