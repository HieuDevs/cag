# Lỗi người Việt hay gặp

## Trật tự từ

| Lỗi | Sửa | Lý do |
|---|---|---|
| ✗ 书我的 | ✓ 我的书 | Định ngữ đứng trước danh từ |
| ✗ 我学习汉语在大学 | ✓ 我在大学学习汉语 | Trạng ngữ nơi chốn đứng trước động từ |
| ✗ 我去北京明天 | ✓ 我明天去北京 | Trạng ngữ thời gian đứng trước động từ |
| ✗ 我两年学习汉语 | ✓ 我学了两年汉语 | Thời lượng là bổ ngữ, đứng sau động từ |
| ✗ 我喜欢很 | ✓ 我很喜欢 | Phó từ mức độ đứng trước động từ, tính từ |
| ✗ 我打电话给他 (chấp nhận được ở một số vùng) | ✓ 我给他打电话 | Giới từ + tân ngữ đứng trước động từ |

## Dùng từ

| Lỗi | Sửa | Lý do |
|---|---|---|
| ✗ 我是很忙 | ✓ 我很忙 | Tính từ làm vị ngữ không cần 是 |
| ✗ 我比他很高 | ✓ 我比他高 / 高得多 | Câu 比 không dùng 很 |
| ✗ 我昨天不去 | ✓ 我昨天没去 | Việc đã qua phủ định bằng 没 |
| ✗ 以前我常常去了 | ✓ 以前我常常去 | Thói quen trong quá khứ không dùng 了 |
| ✗ 我没去过了 | ✓ 我没去过 | Phủ định 过 không kèm 了 |
| ✗ 三书 / 一个书 | ✓ 三本书 | Cần lượng từ đúng |
| ✗ 我会游一千米 | ✓ 我能游一千米 | Mức độ năng lực cụ thể dùng 能 |
| ✗ 他跑很快 | ✓ 他跑得很快 | Bổ ngữ trạng thái cần 得 |
| ✗ 我很喜欢看书非常 | ✓ 我非常喜欢看书 | Chỉ dùng một phó từ mức độ, đặt trước động từ |
| ✗ 我见面他 | ✓ 我跟他见面 | 见面 là động từ ly hợp, không mang tân ngữ |

**Động từ ly hợp** (động từ + tân ngữ đã gộp sẵn) không mang thêm tân ngữ, thành phần khác chen vào giữa: 见面 → 跟他见面, 见了一面; 帮忙 → 帮他的忙; 睡觉 → 睡了八个小时的觉; 结婚 → 跟她结婚; 毕业 → 大学毕业 hoặc 从大学毕业; 游泳, 上课, 考试, 生气 (生他的气).

## Từ Hán Việt dễ hiểu sai

Âm Hán Việt giúp đoán nghĩa rất nhanh, nhưng nhiều từ đã khác nghĩa giữa hai ngôn ngữ:

| Từ | Hán Việt | Nghĩa trong tiếng Trung hiện đại |
|---|---|---|
| 手段 shǒuduàn | thủ đoạn | biện pháp, cách thức (thường trung tính; có thể mang nghĩa xấu tùy ngữ cảnh) |
| 告诉 gàosu | cáo tố | nói cho biết (không phải "tố cáo") |
| 表情 biǎoqíng | biểu tình | nét mặt, biểu cảm ("biểu tình" phản đối là 示威 shìwēi, 游行 yóuxíng) |
| 爱人 àiren | ái nhân | vợ hoặc chồng (ở Trung Quốc đại lục) |
| 大家 dàjiā | đại gia | mọi người |
| 东西 dōngxi | đông tây | đồ vật (dōngxī: phía đông và phía tây) |
| 小心 xiǎoxīn | tiểu tâm | cẩn thận |
| 生气 shēngqì | sinh khí | tức giận |
| 新闻 xīnwén | tân văn | tin tức |
| 经理 jīnglǐ | kinh lý | giám đốc, quản lý (trong doanh nghiệp) |
| 工作 gōngzuò | công tác | công việc, làm việc ("đi công tác" là 出差 chūchāi) |
| 学院 xuéyuàn | học viện | khoa (trong trường đại học) hoặc trường đại học chuyên ngành |
| 困难 kùnnan | khốn nan | khó khăn (không mang nghĩa chửi mắng như tiếng Việt) |
| 老婆 lǎopo | lão bà | vợ (khẩu ngữ), không phải "bà già" |
